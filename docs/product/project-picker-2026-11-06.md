# 项目选择器

决定：采用可搜索浮层，替换用量页面的原生项目下拉框。目标是让编码路径、中文路径、同名项目和大量临时目录仍然可查找、可区分，长路径不撑开窗口。

- 项目名称、路径两行展示；路径解码仅用于显示和搜索，筛选保留原始值。
- 浮层宽度 360px，上限为视口宽度减 32px；项目列表内部滚动。
- 支持全文路径搜索、方向键、Enter、Esc、Tab 和点击外部关闭。
- 按已读取会话的最近活动排序，跨来源取最大时间；筛选后保留同范围中已知的活动时间。没有会话时间的项目排后，按路径排序。时间范围、来源、模型切换后重置。
- 临时目录保留，不按目录名猜测分类，不合并同名项目。
- 放弃条件：若实际数据中临时目录仍持续妨碍定位项目，再评估明确的目录筛选，不扩展为项目管理系统。

验证：npm run build；node scripts/check_project_picker.mjs。浏览器使用模拟 IPC，覆盖中文编码路径、同名项目、最近活跃排序、浮层尺寸、搜索、键盘选择、原始筛选值、无结果提示、Esc 焦点恢复与外部关闭；截图位于 /tmp/quotabar-project-picker-dark.png。

2026-11-07 原生复验：已在安装的 macOS App 中打开项目浮层，搜索当前项目并确认结果，再关闭浮层；来源下拉框焦点描边完整覆盖图标和文字。托盘与分析窗口均已实际打开。
